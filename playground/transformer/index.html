Attention Is All You Need • 2017 • Encoder-Decoder Transformer

Transformers From Signals To Gradients

This page teaches the original Transformer paper at implementation depth. It follows the full computation graph: token embeddings, positional encodings, scaled dot-product attention, multi-head attention, residual paths, feed-forward layers, masking, cross-entropy loss, and the backward pass through softmax and attention.

Encoder stack: N = 6 layers Decoder stack: N = 6 layers d_model = 512 h = 8 heads d_k = d_v = 64 d_ff = 2048

Global View

The paper replaces recurrence with attention. Every encoder token can attend to every other encoder token. Every decoder token can attend to earlier decoder tokens and to the full encoder output. The resulting path length between distant positions becomes O(1) attention hops instead of O(n) recurrent steps.

Attention(Q, K, V) = softmax((QKT) / √dk)V
MultiHead(Q, K, V) = Concat(head1, ..., headh)WO
headi = Attention(QWiQ, KWiK, VWiV)

The key idea is not just attention. It is the combination of parallel token processing, multi-head subspaces, residual optimization, and explicit positional structure.

1. Data Flow Through The Original Paper

Token Embeddings

Each source token x_t and target token y_t is mapped to a dense vector.

E ∈ ℝ|V| × d_model
z_t = E[x_t] · √d_model

The paper scales embeddings by √d_model so the embedding magnitude is compatible with the residual stream. The output projection weights are tied with the embedding matrix in the paper's experiments.

Sinusoidal Positional Encoding

Because attention is permutation-equivariant, the model needs explicit position signals.

PE(pos, 2i) = sin(pos / 100002i / d_model)
PE(pos, 2i + 1) = cos(pos / 100002i / d_model)
h_t(0) = z_t + PE_t

The sinusoid frequencies form a geometric ladder, making relative offsets linearly recoverable in principle.

Encoder Layer

An encoder layer applies self-attention then a position-wise MLP, each wrapped by residual addition and normalization.

u = LayerNorm(x + MultiHead(x, x, x))
y = LayerNorm(u + FFN(u))

In the original paper, normalization is post-residual. Many modern implementations use pre-norm for stability, but the 2017 formulation is the one shown here.

The tradeoff is quadratic token-token interaction cost: O(n² d_model).

Decoder Layer

The decoder has three sublayers instead of two.

u = LayerNorm(x + MaskedMultiHead(x, x, x))
v = LayerNorm(u + MultiHead(u, H_enc, H_enc))
y = LayerNorm(v + FFN(v))

Masked self-attention prevents information leakage from future target tokens during training.

Cross-Attention Semantics

In decoder cross-attention, queries come from the partial target sequence, while keys and values come from the encoder outputs. This lets the decoder decide which source positions matter for the next target token.

Q = U WQ, K = H_enc WK, V = H_enc WV

Output Projection

The decoder output at each position is mapped to vocabulary logits.

o_t = h_t WOvocab + b
p_t = softmax(o_t)

The highest-probability token is used at inference, but training compares the whole distribution against the target token.

Autoregressive Shift

Training uses teacher forcing: the decoder input is the gold target sequence shifted right with a begin token. The model predicts the next token at every position in parallel.

Cross-Entropy Loss

L = - Σt log p_t(y_t)

The paper also uses label smoothing with εls = 0.1, which prevents overconfident distributions.

ỹ = (1 - ε) · one_hot(y) + ε / |V|
L = - Σi ỹ_i log p_i

3. Multi-Head Attention As Learned Subspace Routing

Linear Projections

The model learns different query, key, and value projections per head.

Qi = XWiQ
Ki = XWiK
Vi = XWiV

Independent Attention Maps

One head may learn syntactic dependencies, another long-range agreement, and another punctuation or positional structure. The paper's insight is that forcing all structure into one attention map is a bottleneck.

Concatenate And Mix

After each head emits d_v-dimensional outputs, the model concatenates them and mixes them through one output projection.

H = Concat(head1, ..., headh) ∈ ℝn × hd_v
Y = HWO

4. Residual Stream, LayerNorm, And Position-Wise MLP

Residual Paths

The hidden state is a running information highway. Each sublayer proposes an update, and the residual path preserves the old representation.

r = x + Sublayer(x)

This helps gradient flow and stabilizes very deep networks.

Layer Normalization

μ = (1 / d) Σ x_i
σ² = (1 / d) Σ (x_i - μ)²
LayerNorm(x)_i = γ_i (x_i - μ) / √(σ² + ε) + β_i

Normalization is applied independently per token vector across features, not across the batch.

Position-Wise Feed-Forward Network

The same MLP is applied to every sequence position independently. This is where the model performs non-linear channel mixing after the token mixing performed by attention.

FFN(x) = max(0, xW1 + b1)W2 + b2

The paper uses ReLU here. Many modern descendants switch to GELU or gated variants.

5. Step-By-Step Backpropagation And Loss Gradients

Cross-Entropy With Softmax

p_i = exp(o_i) / Σ_j exp(o_j)
L = - Σ_i y_i log p_i
∂L / ∂o_i = p_i - y_i

This is one of the most important identities in deep learning. The gradient on the logits is simply predicted probability minus target probability.

Interpretation

If the correct token has low probability, its logit receives a large negative gradient, pushing it upward after the optimizer step. Incorrect high-probability tokens receive positive gradients, pushing them downward.

o = [1.7, 0.2, -0.4], y = [1, 0, 0]
p ≈ [0.72, 0.16, 0.12]
∂L / ∂o ≈ [-0.28, 0.16, 0.12]

Attention Probabilities

A = softmax(S)
O = AV

Suppose the loss gradient reaching the head output is G = ∂L / ∂O.

∂L / ∂A = G VT

Softmax Jacobian

For one attention row a = softmax(s), the Jacobian is:

Jsoftmax(s) = diag(a) - aaT
∂L / ∂s = Jsoftmax(s) (∂L / ∂a)

This means increasing one probability must reduce others because each row sums to one.

Scaled Scores

S = QKT / √dk

Let GS = ∂L / ∂S. Then:

∂L / ∂Q = GS K / √dk
∂L / ∂K = GST Q / √dk

Why The Scale Matters

Without division by √d_k, the dot products grow with dimensionality, softmax saturates, and gradients collapse toward zero because the probability distribution becomes too sharp.

Gradient To Values

O = AV
∂L / ∂V = AT G

Intuitively, if a value vector was heavily attended by many queries, it accumulates a larger share of gradient.

Back Through Projections

Q = XWQ, K = XWK, V = XWV
∂L / ∂WQ = XT(∂L / ∂Q)
∂L / ∂X += (∂L / ∂Q)WQ,T

The same pattern applies to W^K and W^V.

Residual Gradient Splitting

For r = x + f(x), the incoming gradient is copied into two paths.

∂L / ∂x = ∂L / ∂r + (∂L / ∂r)(∂f / ∂x)

This direct identity path is one reason residual networks optimize far better than plain deep stacks.

Gradient Story For One Decoder Token

The loss at one target position sends signal backward into the output projection, decoder feed-forward, decoder self-attention, decoder cross-attention, and then into whichever encoder states influenced that prediction. The full model is trained by this dense web of routing decisions.

7. Original Paper vs Modern Variants

Original Paper

Encoder-decoder, sinusoidal positions, post-norm, ReLU FFN, machine translation target.

GPT-Style Decoder

Decoder-only, causal mask only, often learned positions, pre-norm, next-token language modeling.

BERT-Style Encoder

Encoder-only, bidirectional masking during pretraining, masked language modeling instead of autoregressive decoding.

If you inspect the local Python implementation in this playground, you will notice it is a decoder-only causal Transformer, which is closer to GPT than to the original full encoder-decoder paper.

8. Mental Model

Forward Pass Intuition

Every layer alternates between token mixing and channel mixing. Attention decides who talks to whom. The feed-forward network decides how each token transforms its internal features.

Backward Pass Intuition

Gradients ask: which logits were wrong, which hidden features caused those logits, which attention paths exposed those features, and which query/key/value projections made those paths probable?
